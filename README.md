# The Control Room — 90-Day SDE / Senior Data Engineer Prep

A single-page, day-by-day interview-prep tracker for a FAANG-track Senior Data Engineer plan.
No build step, no backend — just one `index.html`. Progress saves automatically in your browser
(`localStorage`).

**Live site:** https://raja9283.github.io/interview-prep/

## Features

- **91-day plan** (13 weeks × 7 days) — 6 study days + 1 review/mock day per week.
- **Daily progress tracking** — check off tasks; per-day, per-week, per-phase, and overall progress
  update live, with a streak counter.
- **"Today" engine** — set your Day 1 start date and it highlights exactly which day you're on,
  with a *Jump to today* button.
- **Curated resources on every topic** — 2–3 hand-picked, verified links per
  Data Engineering / Cloud / DevOps / AI / System-Design topic, plus track-level links to:
  - DSA → [Striver's A2Z Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z)
  - SQL → [DataLemur](https://datalemur.com/questions)
  - System Design → [DesignGurus — Grokking SD Fundamentals](https://www.designgurus.io/course/grokking-system-design-fundamentals)
  - Data Engineering → [DataPathsala](https://www.datapathsala.com/)

## Run locally

It's a static file — just open `index.html` in any browser. (Optionally serve it: `npx serve .`)

## Tech

Plain HTML/CSS/JS, no dependencies. Hosted on GitHub Pages.
